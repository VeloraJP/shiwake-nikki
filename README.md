# 汎用仕訳日記帳

スマートフォンやPCで仕訳を入力し、主要な会計ソフトの取り込み形式に変換して出力するためのWebアプリです。ブラウザで開くだけで使え、インストールは不要です。

公開URL: https://velorajp.github.io/shiwake-nikki/

## 特徴

- 入力した仕訳データは、お使いの端末のブラウザ内にのみ保存されます。サーバーへの送信は行いません。
- 原則は一本仕訳で、複合仕訳は「諸口」を経由して分解する方式です。
- 複数会社の切り替えに対応します。
- 合計残高試算表（A4横・左に貸借対照表、右に損益計算書）を表示します。
- 仕訳の検索、貸借が合わない伝票などの「要確認」チェック、出力済みの管理ができます。

## 対応する出力形式

- 本ツール間の転送用JSON
- freee
- エプソン財務会計
- JDL
- 弥生会計（デスクトップ版）
- マネーフォワード クラウド会計
- PCA会計
- 勘定奉行（デスクトップ版）

制作者が実務で実際に使用したことがある会計ソフトは、エプソン財務会計とJDLのみです。エプソンとJDLの形式は、実務で使っている変換プログラムの実績を土台にしています。それ以外の形式（freee、弥生会計、マネーフォワード クラウド会計、PCA会計、勘定奉行）は公開資料のみに基づいて実装しており、制作者は実機に触ったことがありません。未検証です。

また、エプソン・JDLを含め、本ツールが出力したファイルを取り込み先の実機で取り込めるかの確認は、全形式で未実施です。各形式の根拠と検証状況は、アプリ内の「対応形式と検証状況」に記載しています。取り込み前には、必ず内容をご確認ください。

## 注意事項

- このツール自体は、税法で定められた帳簿の要件（電子帳簿保存法に基づく保存要件など）を満たすものではありません。正式な帳簿は、取り込み先の会計ソフト側で作成・保存してください。
- 各会計ソフト用の科目コードと税区分の番号は、初期値を持ちません。お使いの事務所・会社で使っているコードを、科目マスタ・税区分マスタにご自身で登録してください（科目名などの名称は初期設定されています）。
- 本ツールの利用によって生じた損害について、開発者は責任を負いません。出力したファイルの内容は、取り込み前に必ずご確認ください。

## 使い方の流れ

1. 会社を登録する（会社名と会計期間）
2. 必要に応じて、科目マスタに会計ソフト用のコードを登録する
3. 日々の仕訳を入力する
4. 出力タブで形式を選び、ファイルを生成する
5. 生成したファイルを会計ソフトに取り込む

スマートフォンで入力した仕訳は、転送用JSONでPCへ移して集約することもできます。

本ツールは制作途中の開発版です。より良いものにしていくため、不具合の報告、改善点、ご要望を歓迎しています。X（旧Twitter）の専用アカウントのDMで受け付けていますので、お気軽にお寄せください。再現手順（どの形式で、どんな仕訳で、何が起きたか）があると大変助かります。

あわせて、検証へのご協力のお願いです。制作者が実機に触ったことのない形式（freee、弥生会計、マネーフォワード クラウド会計、PCA会計、勘定奉行）については、実際の会計ソフト側の情報が不足しています。次のような情報をお寄せいただけると、検証が大きく進みます。ご協力いただけると本当にありがたいです。

- 実際のソフトから出力した仕訳ファイル（ダミーの仕訳数件分で構いません）
- 本ツールのファイルを実際に取り込んだ結果（成功したか、エラーが出た場合はその文面）

情報をお送りいただく際は、会社名、氏名、取引先名、口座番号など、個人情報や機密にあたる部分は必ず消してください。金額や摘要も、実データの場合はダミーの内容に置き換えたもので構いません。

いただいたご意見にはすべて目を通しますが、対応や修正をお約束できるものではありません。あらかじめご了承ください。
